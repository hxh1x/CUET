## 2. File Inventory and Details

### 2.1 Canonical Source Documents (`01_MASTER_SYLLABUS/`)
- **`SCQP09_Master_Syllabus_2024-2026.pdf`** (487,808 bytes): Comprehensive 50-page syllabus compiled from the 225 questions across 2024, 2025, and 2026 papers.
- **`SCQP09_Master_Syllabus.html`** (216,240 bytes): HTML representation of the master syllabus, generated by `build_master_syllabus.py`.
- **`SCQP09_Master_Taxonomy.csv`** (49,432 bytes, 93 lines): Structured taxonomy listing 92 modules across Mathematics, Thinking & Decision Making, Digital Fundamentals, Data Structures & Algorithms, Operating Systems, and Rare/Legacy CS.

### 2.2 Question Bank Data (`02_QUESTION_BANK/`)
- **`SCQP09_Question_Bank_2024-2026.csv`** (87,037 bytes, 226 lines): 225 questions classified by `year`, `qno`, `subject`, `topic`, `subtopic`, and `question_text`.
  - 2024: 75 questions
  - 2025: 75 questions
  - 2026: 75 questions
- **`SCQP09_Question_Bank_2024-2026.json`** (173,178 bytes): JSON array of 225 question records with keys `year`, `qno`, `text`, and `lines`.

### 2.3 Primary Source Papers (`03_ORIGINAL_PAPERS/`)
- **`SCQP09_2024_March19_Shift3.pdf`**: Official NTA examination paper from March 19, 2024 (Shift 3).
- **`SCQP09_2025_March27_Shift2.pdf`**: Official NTA examination paper from March 27, 2025 (Shift 2).
- **`SCQP09_2026_March11_Shift2.pdf`**: Official NTA examination paper from March 11, 2026 (Shift 2).

### 2.4 Reference Documentation (`04_REFERENCE/`)
- **`NFSU_Gandhinagar_MSc_CyberSecurity_Eligibility.md`**: Program eligibility criteria for National Forensic Sciences University M.Sc. Cyber Security.

### 2.5 Build and Pipeline Scripts (`05_SOURCE/`)
- **`build_master_syllabus.py`** (96,872 bytes): Script that joins questions with taxonomy rows, verifies coverage, and generates the master syllabus HTML and PDF via WeasyPrint.
- **`classify_recent.py`** (18,502 bytes): Python dictionary mapping all 225 question numbers across 2024, 2025, and 2026 to `(subject, topic, subtopic)`.
- **`parse_questions.py`** (6,519 bytes): OCR extraction and question parsing script targeting PyMuPDF and OCR outputs.
- **`taxonomy_data.py`** (68,480 bytes): 92 module definitions (`ROWS`) specifying subject, module name, title, keys, learning objectives, exam question types, and examples.

### 2.6 Legacy Duplicate Directory (`SCQP09_MASTER_SYLLABUS/`)
- Contains older/duplicate copies of `build.py`, `SCQP09_Master_Syllabus.html`, `SCQP09_Master_Syllabus_2024-2026.pdf`, `SCQP09_Master_Taxonomy.csv`, and `taxonomy_data.py`. This folder is retained for historical provenance but is designated as legacy. All active work is rooted in `CUET_SCQP09_FINAL/`.
