# CUET-PG SCQP09 Master Curriculum & 92-Module Syllabus

**Target Examination:** NTA CUET-PG SCQP09 (Computer Science / MCA / Cyber Security)
**Total Modules:** 92 Modules across 6 Core Tracks
**Total Verified Exam Questions:** 225 Questions (2024, 2025, 2026)

---

## 1. Curriculum Architecture & Priority Framework

Every module is assigned a preparation priority based on empirical question frequency across official papers:
- **Priority P0 (Critical Yield, 5+ questions):** Non-negotiable high-yield modules. Account for >40% of the exam score.
- **Priority P1 (Core Yield, 3-4 questions):** Essential recurring modules tested every year.
- **Priority P2 (Standard Yield, 1-2 questions):** Regularly tested topics requiring standard competence.
- **Priority P3 (Foundational / Insurance, 0 questions in 2024-2026):** Theoretical foundations and official syllabus insurance.

## 3. Track-Wise Breakdown & Study Strategy

### 3.1 Track 1: Mathematics (M1 to M22)
- **Total Weightage:** 70 / 225 questions (31.1%)
- **Core Focus:** Sets, Relations, Permutations, Probability, Matrices, Coordinate Geometry, and Calculus.
- **Learning Progression:** Set Foundations (M1) -> Counting & Probability (M2-M4) -> Algebra Toolkit (M5-M8) -> Linear Algebra & Matrices (M9-M10) -> Coordinate Geometry (M11-M16) -> Differential & Integral Calculus (M17-M22).

### 3.2 Track 2: Thinking & Decision Making (T1 to T17)
- **Total Weightage:** 50 / 225 questions (22.2%)
- **Core Focus:** Fast-scoring daily practice modules: Number & Letter Series, Blood Relations, Direction Sense, Seating, Coding-Decoding, and Syllogisms.
- **Learning Progression:** Pattern Recognition (T1-T2) -> Spatial & Direction (T3-T4) -> Associative & Semantic (T5-T6) -> Relational & Structural (T7-T9) -> Real-World & Visual (T10-T13) -> Formal Deductive Logic (T14-T17).

### 3.3 Track 3: Digital Fundamentals (G1 to G17)
- **Total Weightage:** 35 / 225 questions (15.6%)
- **Core Focus:** Number Systems, Boolean Simplification, Logic Gates, Combinational Blocks (MUX, Decoders), Sequential Elements (Flip-Flops, Counters, Registers).
- **Learning Progression:** Representations (G1-G3) -> Gate Logic & Minimization (G4-G6) -> Arithmetic Circuits (G7-G10) -> Sequential Logic (G11-G14) -> Memory & Architecture (G15-G17).

### 3.4 Track 4: Data Structures & Algorithms (D1 to D17)
- **Total Weightage:** 35 / 225 questions (15.6%)
- **Core Focus:** Arrays, Linked Lists, Stacks, Queues, Binary Search Trees, Heaps, Sorting, Graph Traversals (BFS/DFS), and Asymptotic Analysis.
- **Learning Progression:** Linear Structures (D1-D3) -> Hierarchical Tree Structures (D4-D7) -> Complexity Analysis (D8) -> Sorting & Searching (D9) -> Graph Algorithms (D10-D13) -> Algorithmic Paradigms (D14-D17).

### 3.5 Track 5: Operating Systems (O1 to O16)
- **Total Weightage:** 34 / 225 questions (15.1%)
- **Core Focus:** Process Scheduling, Synchronization, Semaphores, Deadlock Handling (Banker's Algorithm), Paging, and Page Replacement Algorithms.
- **Learning Progression:** OS Fundamentals & CPU Scheduling (O1-O2) -> Concurrency & Deadlocks (O3-O5) -> Memory Architecture & Virtual Memory (O6-O8) -> Storage, Files & Disks (O9-O12) -> Protection & Advanced Topics (O13-O16).

### 3.6 Track 6: Low-Yield Official CS / DBMS / CN (R1 to R3)
- **Total Weightage:** 1 / 225 questions (0.4%)
- **Core Focus:** Minimum-effort insurance coverage. Only 1 transaction question in 2024 and 0 CN questions in 3 years. Allocate no more than 3-4 hours of high-level revision before the exam.
